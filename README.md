## 🚀 Quick Start

### Option 1: Open directly in browser
Simply open `index.html` in any modern browser. No server required for basic usage.

### Option 2: Local development server
```bash
npm install
npm start
# Opens at http://localhost:3000
```

### Option 3: Generate PDFs
```bash
npm install
npm run generate-pdf          # Generate all 30 day PDFs
npm run generate-pdf -- --day 1   # Generate Day 1 only
```

## 🎯 What's In Every Daily Lesson

Each 60–90 minute lesson contains **21 structured modules**:

| # | Module | Content |
|---|--------|---------|
| 1 | Daily Motivation | Motivational quote + success mindset lesson |
| 2 | Warm-up Conversation | 10 practice questions with grammar feedback |
| 3 | Vocabulary (25 words) | IPA, POS, meaning, synonyms, antonyms, 4 examples |
| 4 | Phrasal Verbs (10) | Meanings, usage, 3 domain examples, exercises |
| 5 | Idioms (10) | Origins, meanings, interview & corporate examples |
| 6 | Grammar Deep Dive | Rules, formulas, timelines, 5 exercise types |
| 7 | Speaking Practice (20) | Escalating difficulty speaking questions |
| 8 | Role-Play Conversations (5) | Friend/Teacher/HR/Manager/Customer scripts |
| 9 | Pronunciation (20 words) | IPA, syllable stress, minimal pairs, audio |
| 10 | Reading Practice | 400-word article + comprehension questions |
| 11 | Listening Practice | TED Talk + guided focus questions |
| 12 | Writing Practice | Email, post, or letter with model answer |
| 13 | HR Interview Coaching | Bad → Good → Excellent answer progression |
| 14 | Technical Communication | CS concepts in professional interview English |
| 15 | Group Discussion | Topic, opening, counter-arguments, conclusion |
| 16 | Storytelling Challenge | 2-minute scenario speech with timer |
| 17 | Rapid Fire (20 questions) | 5-second quick answer challenges |
| 18 | Indian English Mistakes (10) | Common errors corrected with explanations |
| 19 | Daily Revision Quiz | Vocabulary + grammar quizzes with scoring |
| 20 | Homework (7 tasks) | Mirror practice, recording, shadowing tasks |
| 21 | Daily Evaluation | 8-dimension self-assessment with radar chart |

## ⚙️ Technology Stack

- **Core**: Pure HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Fonts**: Google Fonts (Inter, Outfit, JetBrains Mono)
- **Icons**: Font Awesome 6.5
- **Charts**: Chart.js 4.4 (radar charts, line charts)
- **Audio**: Web Speech API (pronunciation + shadowing)
- **Storage**: localStorage (progress, settings, achievements)
- **PDF**: Puppeteer (headless Chrome, Node.js)
- **Search**: Custom full-text search engine (no external library)
- **Design**: CSS Custom Properties (design tokens), Glassmorphism, Dark Mode
